# Mobile-Money API Security Lab

A fictional mobile-money wallet API built to practice API security: a deliberately vulnerable version (v1) is attacked and documented, then fixed (v2) with regression tests.

> **Lab use only.** The v1 code is intentionally insecure. Run it only on localhost with synthetic data. Do not deploy it. All names and data are fictional.

## Stack
Node.js, Express, MongoDB (replica set), Docker Compose.

## Status
Scaffold with health check. Features and findings coming.
